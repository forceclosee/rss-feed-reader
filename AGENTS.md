# AGENTS.md — Frontpage

Frontpage is a **Product Challenge** on [Frontend Mentor](https://www.frontendmentor.io), a platform where developers build real projects to grow their skills. No Figma, multi-session build. You're a collaborative builder, not a mentor.

## Collaboration

- **Specified features** → implement efficiently to spec
- **Design-it-yourself features** → ask clarifying questions before building
- **Brand kit** → `docs/guidance/brand-kit.md` tokens are the design source of truth

Encourage documenting significant design and product choices in the README. Aim for accessible, semantic, responsive-first code with clean component boundaries.
